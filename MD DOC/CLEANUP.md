The source-only industry ZIP was superseded at the user's request by
release_assets/industry/PPE_Detection_Windows.zip, containing selected models
and recipient-PC setup scripts. Factory videos, full training datasets and
the current machine's engines remain outside this delivery.

## Two-camera handoff cleanup, 21 October 2026

- Replaced the single-camera session/UI and unscoped stream endpoint with paired
  camera capture and separate face/feet streams; no duplicate implementation remains.
- Removed tools/install_engine.py and the obsolete TOML engine discovery, legacy
  ModelSpec adapter and unused TensorRTEngine.detect wrapper. Their only remaining
  callers were legacy tests. Production inference/export use the versioned registry;
  hash checks, engine class identity and output-shape validation remain.
- Replaced legacy installer tests with current atomic-copy failure preservation
  and TensorRT registry tampering tests. Removed the unused video-test import.
- Removed ONNX CUDA provider code/options. ONNX Runtime is optional CPU-only;
  TOML parsing is now a training/development dependency instead of an app dependency.
- Replaced stale setup/camera instructions, consolidated shared badge styling,
  and formatted the stylesheet. Training, export and diagnostic tools with active
  purposes remain; no datasets, footage, models, selected runs or historical
  evidence was deleted. The removed tracked installer can be recovered from Git.
- The industry source bundle is generated from the existing explicit allowlist.
  It rejects source symlinks escaping the workspace and stops on credential-pattern
  matches. It includes current dependencies, design context and browser checks;
  it excludes factory media, datasets, model binaries, environments and Git history.
- No commit, push, history rewrite, HP runtime install or engine build occurred.

Paths are relative to the repository root. Current datasets, selected runs,
`.venv` and `Previous/` are preserved. All original root Markdown files were
copied to ignored `local/document_history/*.txt` before consolidation.
